# Подсчёт просмотров #BXDBATTLE (TikTok + Instagram), разовый запуск

## Установка
    pip install -r requirements.txt

## Подготовка
1. Заполните `bloggers.csv` (133 строки): `name,tiktok,instagram`.
   Ник можно писать как `@nick`, `nick` или ссылкой на профиль. Пустое поле = нет аккаунта.
2. Аккаунты блогеров должны быть публичными.

## Запуск
    python bxd_count.py --start 2026-10-01 --end 2026-10-28

Полезные параметры:
- `--tz Asia/Almaty` — часовой пояс периода (по умолчанию Алматы/Астана)
- `--hashtag BXDBATTLE` — хэштег без `#`
- `--ig-login служебный_аккаунт` — вход в Instagram служебным аккаунтом (не личным!), меньше блокировок
- `--skip-ig` / `--skip-tt` — собрать только одну платформу
- `--max-videos 80` — сколько последних роликов смотреть у каждого аккаунта

Скрипт сохраняет прогресс в `cache.json`. Если оборвался (блокировка, интернет), просто
запустите ту же команду ещё раз: готовые блогеры пропускаются. Для полного пересбора удалите `cache.json`.

Время работы: примерно 1–2 секунды на ролик плюс паузы; на 133 блогера порядка 30–60 минут.

## Результат: result.xlsx
- **Рейтинг** — сортировка по сумме просмотров (TikTok + Instagram); колонка «Статус данных»
  показывает, у кого что не удалось получить.
- **Ролики** — все засчитанные ролики со ссылками (для проверки).
- **Проблемы** — ошибки по аккаунтам.

## Важно
- Это неофициальное чтение публичных страниц: Instagram может блокировать, часть данных
  может не прийти. Такие случаи помечены в «Статусе данных»; их нужно перепроверить
  или дописать вручную. Нули вместо отсутствующих данных скрипт не подставляет как «ок».
- Засчитываются только ролики, где в подписи есть `#BXDBATTLE` и дата входит в период.
- Количество роликов в рейтинг не влияет.
